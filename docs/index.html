Features
Everything you need to
detect and prevent telecom fraud

Multi-modal AI analysis combining voice, video, and text signals into a single explainable risk verdict.

🎙️

ASR Transcription

Whisper-based speech-to-text running locally on CPU (int8 quantised). Auto-detects language from audio.

🤖

Voice Anti-Spoof

AASIST deep learning model detects AI-generated and cloned voices with high accuracy. Falls back to heuristics gracefully.

🎬

Video Deepfake

OpenCV Haar cascade frame-level analysis detects face manipulation, frame duplication, and editing artefacts.

📝

Scam Classifier

TF-IDF + Logistic Regression matching 6 fraud categories: digital arrest, fake courier, OTP phishing, kin emergency, and more.

📊

Explainable Risk Engine

Weighted aggregation across all detectors. Every score comes with specific red flags and actionable next steps — not a black box.

👨‍👩‍👧

Family Safe-Voice Registry

Pre-enrol family voices. Instantly verify suspicious "relative in trouble" calls against enrolled speaker embeddings.

Detection
Catches 6 types of telecom fraud

The scam classifier is trained on synthetic data generated from I4C/RBI advisory templates and matches real-world scam patterns.

Critical

Digital Arrest Scam

Fake police/CBI/customs impersonation. Threats of arrest, video call demands, "verification fee" payments.

Critical

Fake Courier / Parcel

"Your parcel contains drugs" trap. Creates panic to push bank detail sharing or fee payments.

Critical

OTP / Bank Phishing

Requests for OTPs, PINs, or UPI details. No genuine bank ever asks for these over a call.

Critical

Kin Emergency Fraud

"Your relative is in trouble" — often paired with AI voice cloning to make the impersonation convincing.

Warning

Generic Pressure Tactics

Urgency, secrecy, threats, or requests for personal/financial details in unrecognised patterns.

Safe

Benign Conversation

No scam pattern detected. Normal conversation — restaurant orders, family updates, etc.

Architecture
How DigiRaksha works

A multi-stage pipeline that runs four AI models in parallel and aggregates their outputs into a single explainable verdict.

│ Upload / transcript │ └─ AnalysisPipeline ├─ ASR faster-whisper (CPU int8) → transcript, language ├─ Voice AASIST anti-spoof (PyTorch) → AI-voice score ├─ Video OpenCV Haar cascade → editing score └─ Text TF-IDF + LogisticRegression → scam category + probability └─ RiskEngine weights {voice:0.40, text:0.35, video:0.25} thresholds LOW<40<MEDIUM<65<HIGH critical-escalation (1 crit ×1.05, 2+ ×1.15+0.05) Registry (proactive) MFCC embedding (52-D) → cosine similarity threshold 0.42 (config: verify_similarity_threshold)
Installation
Get started in minutes

Three ways to run DigiRaksha — pick whichever fits your setup.

terminal
git clone https://github.com/Farhaan-jpg/digi-raksha.git cd digi-raksha docker compose up --build -d # → http://localhost:8000 (Full app — React SPA + API) # → http://localhost:8000/docs (Swagger API docs)
backend
cd digi-raksha/backend python -m venv .venv .venv\Scripts\activate pip install -e ".[ml]" uvicorn app.main:app --port 8000
frontend (hot reload)
cd digi-raksha/frontend npm install --include=dev npm run dev # → http://localhost:5173 # → Proxies /api to :8000
Requirements: Python 3.12.x · Node.js 18+ · npm 9+
curl
# Analyse a transcript (sync) curl -X POST http://localhost:8000/api/v1/analyze/transcript \ -H "Content-Type: application/json" \ -d '{"text": "This is CBI, you are under digital arrest. Pay the verification fee."}' # Upload a recording (async → poll job) curl -X POST http://localhost:8000/api/v1/analyze \ -F "file=@data/samples/scam_digital_arrest.wav" # Check scan history curl http://localhost:8000/api/v1/analyze/history
