For your team

Install for your team in minutes.

Two ways in — start with the one-click script, or use the manual steps for full control. Both need the same prerequisites and take 5–10 minutes.

Prerequisites check first

Python — 3.12.x

Exactly 3.12, not 3.13 or 3.14 — the ML audio libraries (librosa, OpenCV) have no wheels for newer Pythons. Tick “Add python.exe to PATH” during install.

py -3.12 --version

Node.js — 20+ LTS

Installer at nodejs.org — the defaults are fine.

node --version

npm — 10+

Ships with Node.js, nothing extra to install.

npm --version

Git

Needed to clone the repository. Install from git-scm.com/download/win.

git --version

OS — Windows 11 / 10

The one-click script is PowerShell-only. Linux / macOS can run the same steps with .venv/bin/python — the commands below use Windows paths.

Path A — One-click setup recommended

Open PowerShell, paste the block below, and let it run. Safe to re-run — it skips anything already installed. It downloads a few hundred MB and prints SETUP COMPLETE when done.

PowerShell · one click
mkdir C:\sih
cd C:\sih
git clone https://github.com/reehaanngp-boop/SIH-2026-TERMINAL-BREAKERS.git
cd SIH-2026-TERMINAL-BREAKERS
powershell -ExecutionPolicy Bypass -File setup_dev.ps1

Path B — Manual setup full control

Step 1

Clone the repository

PowerShell
git clone https://github.com/reehaanngp-boop/SIH-2026-TERMINAL-BREAKERS.git
cd SIH-2026-TERMINAL-BREAKERS
Step 2

Create the Python 3.12 virtual environment

PowerShell
py -3.12 -m venv .venv
Step 3

Install PyTorch first — CPU-only build

Plain pip install torch grabs a multi-GB CUDA build you don’t need. Use the CPU index:

PowerShell
.\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
Step 4

Install the backend + all AI dependencies

PowerShell
cd backend
..\.venv\Scripts\python.exe -m pip install -e ".[ml]"
Step 5

Install the frontend (React / Vite)

PowerShell
cd ..\frontend
npm install --include=dev
cd ..

Gotchas read once

  • Python must be exactly 3.12 — 3.13/3.14 have no wheels for librosa and OpenCV.
  • Install torch from the CPU index before pip install -e ".[ml]", or you download a multi-GB CUDA build.
  • Always pass --include=dev to npm install — a global npm config omit=dev would skip Vite/TypeScript dev dependencies and break the build.
  • Long-path error (“could not read license file” / “filename too long”)? Move the project to a short path like C:\sih and re-run.
  • Smart App Control / antivirus warning on first run? Click Allow / Run anyway, then run the same command once more — it usually resolves.
  • Docker files do not exist in this repo — README/DEPLOYMENT reference docker-compose.yml / Dockerfile, but they aren’t there. Use the local-dev path above.
  • First app launch asks for a 4-digit PIN (access code) — keep it safe.
  • Never commit the .env file — it holds secret API keys. Do a git pull before you start coding.

Run it — two terminals

Keep both windows open. The frontend proxies /api to the backend on port 8000.

Terminal 1 · backend
cd backend
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

→ http://127.0.0.1:8000 — Swagger docs at /docs, health at /api/v1/health

Terminal 2 · frontend
cd frontend
npm run dev

→ http://localhost:5173 — proxies /api to :8000

First launch asks you to create a 4-digit PIN (access code) — keep it safe. Port 8000 already in use? Kill the process using it and retry — the frontend proxy expects the backend on 8000.

Test it & run a demo

Five demo recordings ship with the repo in data/samples/ — you can test without recording anything. Try uploading the scam ones; you should see HIGH risk with the full breakdown.

PowerShell · tests
cd backend
pytest -q                  # all 92 tests (the slow Whisper test takes ~30 s)
pytest -q -m "not slow"    # quick run — skips the slow tests

For developers

API reference.

Interactive docs at /docs (Swagger). Base path /api/v1, grouped System · Analysis · Registry.

System

GET/healthLiveness probe (app, version, API version)
GET/metaDetector availability + official report channels

Analysis

POST/analyze/transcriptAnalyse a raw transcript (sync, JSON body)
POST/analyzeUpload audio / video for analysis (async, multipart)
GET/analyze/jobs/{job_id}Poll analysis job status
GET/analyze/results/{scan_id}Fetch a completed result by scan ID
GET/analyze/historyRecent scan history (default limit 50)

Family Safe-Voice Registry

POST/registry/membersRegister a family member
GET/registry/membersList all family members
DEL/registry/members/{member_id}Remove a member + enrolled voice samples
POST/registry/members/{member_id}/enrollEnrol a voice sample (extracts a speaker embedding)
POST/registry/verifyVerify a suspicious voice note against a member
